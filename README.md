# Afetos | Fotografia e Cinematografia de Casamentos

Este é o site institucional e portfólio da marca **Afetos**, de Jader Figueiredo. Um projeto projetado para transmitir sofisticação, emoção genuína e uma estética cinematográfica e *fine art*.

---

## 🚀 Como Executar Localmente

### Pré-requisitos
* **Node.js** (versão 18 ou superior recomendada)

### Passos para Execução
1. Instalar as dependências do projeto:
   ```bash
   npm install
   ```

2. Executar o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Abrir o navegador no endereço:
   [http://localhost:3000](http://localhost:3000)

---

## 🛠️ Tecnologias Utilizadas
* **React** (v19) com **TypeScript**
* **Vite** (para build ultra-rápido)
* **TailwindCSS** (estilização moderna e fluida)
* **Framer Motion** (animações cinematográficas suaves)
